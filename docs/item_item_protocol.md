# Frozen item-item retrieval experiment

Build one model per existing temporal split using pre-cutoff >=0.50 longest-block qualified canonical airings only. Sparse binary B records presence (not frequency); support n_i=sum B_ui, co-view c_ij=sum B_ui*B_uj. Similarity = c_ij/sqrt(n_i*n_j) * c_ij/(c_ij+20). Exclude self and c<3, retain 50 neighbours per source item; final tie-break ascending raw string programme ID. All training items participate before prediction availability filtering. Use int64 sparse matrix multiplication in blocks of 128 source items, never a dense user-item or full item-item matrix.

User score sums neighbour similarities weighted by log1p(N50_ui), with deterministic source-item iteration. Filter destinations to the unchanged prediction-window pool; all >=0.50 history items may seed the profile, including items not currently available. Standalone direct ranking keeps watched items eligible; retain a separate unseen-only direct ranking. Score ties use ascending raw string ID. Shared v5 fallback uses the original >=0.80 globals and only completes standalone top five; retrieval metrics never include fallback recommendations.

Reuse main fit [2020-03-09,2020-05-18), validation [2020-05-18,2020-07-27), 4625 users/6384 candidates; auxiliary fit [2020-03-09,2020-06-01), validation [2020-06-01,2020-07-27), 4589/5742. Truth and history slices remain original >=0.80; verify original anchor hashes and reconcile saved v5 predictions. No tuning, fusion, final refit or CSV in this round.

Recall@20/50: all-target macro averages hits/number of distinct relevant targets over the whole fixed cohort; micro sums hits/sums targets. For absent targets (relevant minus user's available N50 history), report both all-supported and unseen-only rankings. Conditional macro excludes users with no absent targets; additionally report cohort macro with zero for these users. Micro denominator is total absent targets; report all user/item denominators and exclusion counts. Empty target groups return null conditional recall. Direct list shorter than K is evaluated as is, without fallback.

Incremental coverage unions the whole available personal-history set with top20/50 unseen direct recommendations. Report extra relevant hits, macro and micro coverage and differences from original personal coverage; include union oracle min(5,h)/min(5,|relevant|) as diagnostic only. Candidate-set coverage/oracle is not evidence of improved final ranking or a full-system upper bound.
