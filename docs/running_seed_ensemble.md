Private inputs are generated by the selected-pipeline producers described in reproducing_selected_model.md.

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 VECLIB_MAXIMUM_THREADS=1 python -m src.experiment_seed_ensemble --data-dir /absolute/path/to/the/five/original/files
python -m unittest discover -s tests -v
```

The frozen source-hash inventory includes original data-derived tables, model/CSV controls and coursework reports. The runner refuses to overwrite a fitted seed or candidate CSV. Do not rerun in-place over completed evidence. Inspect the incumbent settings before preparing any independent replay; this run already completed and no further seed/configuration search is authorized.

Stage1 fits seed43 once. Stage2 fits44/45 only after score diversity is observed. Changing only the global seed also changes derived bin-sampling seeds, because the incumbent already samples 200,000 rows for bin construction. Row bagging/feature sampling remain off. Averaging uses the original default binary inference scores, not raw margins; neither is treated as calibrated watch probability. Predictive tree comparison ignores seed metadata and nonpredictive counts/gains.

Only the fixed four-seed mean can qualify for a final artifact. Final inference applies all four historical classifiers unchanged; both validators and a checksum are required. There is no Kaggle upload workflow. Keep private artifacts ignored and coursework reports unchanged until the user supplies a manual result.
